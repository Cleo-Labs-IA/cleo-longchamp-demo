# Cleo × Longchamp

Démo de veille réglementaire dérivée de la version LVMH mise en ligne le 27 octobre 2026. Données et visuels intégrés à `index.html` ; carte interactive disponible hors ligne.

Catégories du brief : textile, cuir, souliers, lunettes, parfum, bijoux et emballages. Marchés : Europe, France, Chine, Japon, Corée, Moyen-Orient, États-Unis et Canada.

L’inventaire historique provient du compte Longchamp le plus récemment créé dans Insight. Aucun mélange des espaces homonymes. Les références historiques ne sont pas présentées comme juridiquement revalidées ; les fiches d’analyse renvoient aux sources officielles consultées. Le Moyen-Orient reste à préciser pays par pays.

`sources.html` documente la requête, les comptes, la déduplication et les sources primaires. Les analyses et actions proposées par Cleo doivent être relues avant une décision de conformité. Cette démonstration ne prétend pas fournir une couverture exhaustive.

Les visuels textile, cuir, souliers, lunettes et bijoux sont les captures fournies par Naomie le 28 octobre 2026. Les pictogrammes parfum et emballages sont illustratifs.

Publication via GitHub Pages, branche main. Aucun secret, export client brut, identifiant de connexion ou document interne n’est inclus dans ce dépôt.
